- Recursos didáticos  
- Avaliação

### 🌐 Introdução à Programação Web

A disciplina combina **design visual** e **tecnologias web** para criar interfaces funcionais e atraentes.

---

### 🔄 Versionamento e Deploy

- Controle de versões permite:
  - Recuperar versões anteriores
  - Trabalhar em equipe
  - Criar branches para desenvolvimento paralelo

- Ferramentas citadas:
  - GitHub
  - GitLab
  - Bitbucket

- Conceitos importantes:
  - Deploy (implantação de aplicações)
  - Ambientes de desenvolvimento
  - Integração Contínua (CI/CD)
  - Automação e boas práticas

---

### 🏗️ Arquitetura de um Site

- Definição de escopo do projeto  
- UX/UI  
- Validação de ideias  
- Usabilidade  
- Prototipação  
- Iteração contínua  

---

### ⚙️ Introdução ao JavaScript (Vanilla JS)

- Linguagem essencial do front-end
- JavaScript puro, sem bibliotecas externas
- Permite:
  - Manipulação da página
  - Comunicação com servidores
  - Implementação da lógica da interface

---

### 🖥️ Servidores, Hospedagem e CMS

- Conceito e importância
- Criação de sites sem codificação intensiva
- Configuração, personalização e instalação de plugins

---

### 🧱 Website Builders

**Vantagens:**
- Facilidade de uso  
- Rapidez  
- Custo-benefício  
- Templates prontos  

**Limitações:**
- Flexibilidade reduzida  
- Possível impacto na performance  
- Migração complexa  

---

### ⚛️ Frameworks Front-end

- React, Vue e Angular
- Componentização
- Gerenciamento de estado
- Rotas
- Integração com APIs

---

### 🛠️ Frameworks Back-end

- Padrões MVC
- APIs REST
- Integração com banco de dados
- Autenticação de usuários
- Boas práticas de arquitetura

---

### 🗄️ Banco de Dados NoSQL

- Bancos não relacionais
- Schemas dinâmicos
- Alta escalabilidade horizontal

## ⭐ Dica Importante

Manter um **portfólio de projetos** é fundamental para:

- Demonstrar habilidades práticas
- Facilitar avaliação acadêmica
- Aumentar chances em estágios e empregos
- Desenvolver organização e melhoria contínua

---

## 📝 Avaliação

Fórmula:

(P1 × 0.25) + (P2 × 0.25) + ((PJ + AT) × 0.25)

Onde:
- P1 = Prova 1  
- P2 = Prova 2  
- PJ = Projeto  
- AT = Atividades  

---

## 📌 Atividade da Aula

1. Formar grupos de 3 a 5 integrantes  
2. Definir ideias de projetos  
3. Criar um repositório no GitHub  
4. Inserir este resumo em Markdown  
5. Escolher três sites para análise tecnológica  
6. Criar um quadro colaborativo no Miro e salvar a imagem no repositório  

---

## ✅ Conclusão

A aula apresentou a disciplina, explicou o funcionamento do semestre, introduziu os fundamentos de Programação Web e definiu a primeira atividade prática em grupo.
